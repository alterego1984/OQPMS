# OPERACIÓN: ¿QUÉ PODRÍA MALIR SAL?

Web estática para la invitación al evento del 11 de octubre de 2026.

## Uso
1. Abre `index.html` en un navegador, o súbelo a cualquier hosting estático.
2. Los códigos están definidos en `js/app.js`.
3. Para cambiar comida/bebidas/playlist, edita `index.html`.
4. Para cambiar los códigos, modifica `ACCESS_CODES` en `js/app.js`.
